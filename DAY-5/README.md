## What I Learned

### Dictionaries

A dictionary in Python stores data in **key-value pairs**.

Example:

```python
student = {
    "id": 1,
    "name": "tharun",
    "course": "python",
    "cgpa": 91.54,
    "address": "hyderabad"
}
```
